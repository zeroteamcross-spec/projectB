Audit menyeluruh fitur Marketing (47)

Diuji dengan showroom, marketing, dan buyer uji coba baru (bukan akun asli) — satu transaksi sungguhan dijalankan dari klik link referral sampai komisi tercatat di ledger.
  • Showroom membuat akun Marketing baru (nama, email, password, nomor WA, slug referral) — akun dan link #/af/<slug> langsung aktif.
  • Showroom mengatur komisi umum 5% di halaman Komisi Marketing.
  • Pengunjung membuka link referral — katalog otomatis tersaring ke mobil showroom itu saja, setiap kunjungan tercatat sebagai klik.
  • Pengunjung memilih mobil (Rp 100.000.000), mendaftar sebagai buyer baru langsung di halaman transaksi, lalu membuat Booking Fee Rp 3.000.000 — kode referral tersimpan otomatis di transaksinya.
  • Buyer transfer manual dan unggah bukti; showroom mengonfirmasi bukti transfer.
  • Begitu status transaksi jadi "dp_paid", komisi langsung terbit otomatis: Rp 5.000.000 (5% × Rp 100.000.000) tercatat di ledger komisi.
  • Marketing login dan melihat semuanya benar: Dashboard (total klik/transaksi/komisi), Komisi (rincian ledger), Settlement (status belum dibayar), Notifikasi ("Komisi Affiliate Masuk").
Bug ditemukan & langsung diperbaiki:
  • Tombol "Daftar Pembeli" tidak pernah muncul saat buyer belum login di halaman transaksi — kode sudah membuat tombolnya tapi lupa menempelkannya ke halaman, jadi pengunjung baru dari link marketing hanya bisa lihat tombol "Login dengan Google". Pesan error saat login/daftar gagal juga ikut tidak pernah tampil. Diperbaiki di sumbernya.
Catatan (bukan bug, untuk transparansi):
  • Payout ke marketing (settlement batch oleh Admin) sudah diverifikasi lewat pembacaan kode & struktur database, tapi belum dicoba klik langsung karena butuh akun Admin production yang belum tersedia untuk pengujian ini.
  • Ada dua tempat pengaturan komisi di kode — satu di data akun marketing (tidak dipakai lagi), satu di halaman Komisi Marketing milik showroom (ini yang aktif). Sudah dipastikan lewat pengujian ini bahwa yang menentukan besar komisi adalah halaman Komisi Marketing.

Ditemukan & diperbaiki sambil jalan

Tidak ada dalam daftar permintaan — ditemukan saat menguji, langsung diperbaiki di sumbernya.
  • Password marketing ikut terhapus — efek samping pengecekan URL live (item 38): form sempat mengosongkan password setiap kali pengecekan berjalan di tengah pengetikan.
  • Logo Showroom sempat tidak bisa diklik — deteksi role di header salah baca status login pada percobaan pertama item 39. Dicek ulang sampai berhasil.
  • Favicon showroom tidak pernah benar-benar berubah — ditemukan saat memeriksa item 25: dua tag ikon tersembunyi di kepala halaman karena skrip awal jalan sebelum HTML server selesai dimuat.
  • Logo default berkedip sebelum logo showroom muncul — saat buka/muat ulang halaman showroom. Diperbaiki dua tahap (gambar, lalu nama aplikasi di sebelahnya).
  • #/admin (dan #/seller, #/buyer) sempat salah arah ke katalog publik — regresi dari percobaan mempercepat waktu muat halaman pertama. Ditemukan dari laporan Anda, langsung dikembalikan ke versi aman.
  • API validasi kode referral tidak pernah mengirim logo/favicon showroom — ditemukan saat mengerjakan item 46: query backend tidak pernah mengambil kolom logo header, favicon, dan judul tab showroom untuk halaman marketing. Ditambahkan di sumbernya.
  • Tombol "Daftar Pembeli" tidak pernah muncul di halaman transaksi — ditemukan saat audit item 47: kode tombolnya sudah dibuat tapi tidak pernah ditempelkan ke halaman, plus pesan error login/daftar ikut disembunyikan. Diperbaiki di sumbernya.
