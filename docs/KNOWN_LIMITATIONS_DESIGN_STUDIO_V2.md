# KNOWN LIMITATIONS - DESIGN STUDIO V2

## Runtime Integration

Design Studio V2 is not connected to application runtime yet. Floating button, editor panel, scanner lifecycle, publish UI, rollback UI, health UI, registry UI, and migration UI are dormant artifacts.

## Transport Layer

No endpoints or AJAX transport exist for Design Studio V2 operations. JavaScript modules use adapter contracts only.

## Browser Smoke

Browser smoke scenarios that require active runtime integration are deferred to a future integration phase.
